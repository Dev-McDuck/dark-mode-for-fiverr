# 🌙 Dark Mode for Fiverr

A lightweight Chrome extension that adds a comfortable dark mode to Fiverr, with an adjustable dark-gray background.

> ⚠️ Not affiliated with or endorsed by Fiverr.

## Features
- Dark mode across all of Fiverr, while images and videos keep their normal colors
- On/off switch in the extension's popup
- Slider to choose the background shade, from pure black to dark gray
- No data collection: your settings are only stored locally in your browser

## Installation
1. Download this repository: click the green **Code** button → **Download ZIP**, then unzip it.
2. In Chrome, go to `chrome://extensions`.
3. Turn on **Developer mode** (top-right corner).
4. Click **Load unpacked** and select the unzipped folder.
5. Open or refresh Fiverr. Done!

## Usage
Click the extension icon in Chrome's toolbar (you may need to pin it from the 🧩 puzzle menu) to:
- Toggle dark mode on or off
- Adjust the **Background shade** slider

Changes apply instantly.

## Updating
Download the new version, replace the old folder, then click the reload ↻ button on the extension in `chrome://extensions` and refresh Fiverr.
